# 개미 퀘스트 🐜

쯔꾸르(RPG Maker) 감성의 픽셀 마을을 돌아다니며 판타지 주식을 사고파는 웹 게임입니다.
할머니가 준 종잣돈을 **30일 안에 목표 금액까지 불리면** 클리어!

**▶ 플레이: https://oh-bj.github.io/ant-quest/**

설치 없이 브라우저에서 바로 실행됩니다. 파일 하나(`index.html`)로 만들어져 있고, 외부 라이브러리는 쓰지 않습니다.

## 게임 방법

1. 위쪽 가운데 **증권거래소**에서 주식을 사고팝니다. 장은 09:00에 열려 15:30에 닫히고, 시세는 실시간으로 움직입니다.
2. **게시판**에서 오늘의 소문을 확인하세요. 단, 소문 중 일부는 거짓말입니다.
3. 장중에 `[속보]`가 뜨면 주가가 크게 출렁입니다. 소문을 믿고 미리 움직일지는 당신의 선택.
4. **집**에서 자면 하루가 끝나고 장 마감 리포트가 나옵니다.
5. 30일이 지나면 최종 자산에 따라 칭호를 받습니다.

## 규칙

한국 주식시장 규칙을 본떴습니다.

- **빨강은 상승, 파랑은 하락**
- 하루 가격제한폭 ±30% (상한가 / 하한가)
- 가격대별 호가 단위
- 수수료 0.015%, 매도 시 거래세 0.18%
- 배당: 10·20·30일차 장 마감 때 지급, 배당소득세 15.4%
- 공매도: 총자산 한도 내, 대차료 하루 0.05%
- 시작 가격의 8% 아래로 떨어지면 상장폐지
- 총자산이 0 아래로 떨어지면 파산(게임 오버)

## 그 밖에

- 업적 18개 (판이 바뀌어도 누적), 타이틀 화면에 최고 기록 표시
- 낮 / 노을 / 밤 변화, 비 · 눈 날씨
- 칩튠 배경음악과 효과음 (메뉴에서 끄기 가능)
- 진행 상황은 브라우저(localStorage)에 자동 저장
